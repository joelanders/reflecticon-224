# Where the StarGate 323 core comes from

Copied on 2026-11-12 from the private StarGate 323 project (`~/code/00-next-verilog-sim-explore/stargate323`),
commit `d235284`; `core/sg323.hpp` re-copied on 2026-11-18 at commit `bf3b2d0` (INPUT MUTE, `Controls::input_mute`):

| Here | There | Changes |
|---|---|---|
| `core/sg323.hpp` | `cpp/sg323.hpp` | none: the real-time C++ port of the project's Python model (`sg323/`) |
| `core/sg323_consts.hpp` | `cpp/sg323_consts.hpp` | none: generated by `tools/gen_cpp_consts.py`; circuit-derived constants only (the MNA solve, the U13 dip fit, bilinear filters at 192 kHz), no PROM data |
| `sg323_machine.cpp` | — | new: the kit adapter (the rate bridge at 192 kHz, controls, readouts, the PROM table) |

The plugin holds no PROM bytes: only sizes and SHA-256 hashes. The user supplies the six images as
binary files (the project's `tools/prom_bin.py` converts its text dumps). The predelay labels are the
times the PROM tables give (all 16 checked against the tables at run time).

Checked after the copy (2026-11-12, `sg323_check_machine`):
- the core on 1 s of stereo noise at 192 kHz with the default settings: output identical byte for
  byte to the project's `cpp/run.cpp` built with `-ffp-contract=off`, the kit's flag. Built without
  it (the project's `cpp/build/run`), the two differ by at most 8e-17, from FMA rounding;
- the 128-byte 0803 and the 4K 0806 reads give the same output;
- readouts: all 16 predelay knob labels match the PROMs, the EQ corners;
- an impulse through the host at 48 kHz: predelay knob 8 moves the first reflection by 100.0 ms,
  decay 0 leaves no tail, direct only peaks at the latency (36 samples);
- the kit's host checks at 44.1, 48 and 96 kHz; pluginval strictness 10 on the VST3; the editor
  shot's state round trip gives the same panel;
- a live room or HF EQ change shows at once and takes no allocation on the audio thread;
- the cost is 45x real time on one thread (M-series Mac).

How the C++ core compares with the Python model is in the project's note
`notes/2026-11-12-0400-cpp-core-and-kit-port.md`.
